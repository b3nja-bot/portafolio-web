## 📌 Descripción del Trabajo Práctico

Desarrollo de marca personal y portafolio profesional responsivo aplicando:
- **Filosofía Mobile First**.
- **Componentes de Bootstrap 5** y utilidades Flexbox.
- **Estética Samsung Dark** (fondo negro puro `#000000`, detalles sobrios y tipografía de alto contraste).
- **JavaScript Vanilla ultra-simple y defendible** (sin frameworks ni librerías complejas).
- **Despliegue gratuito en la nube vía GitHub Pages**.

---

## 🛠️ Tecnologías Aplicadas

- **HTML5:** Marcado semántico (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Variables nativas (`:root`), Flexbox, CSS Grid, transiciones suaves y estética Samsung.
- **Bootstrap 5.3:** 
  - *Filosofía Mobile First:* Sistema de rejillas responsivo (`col-12` en móvil, `col-md-4` en escritorio).
  - *Utilidades Flexbox:* `d-flex`, `align-items-center`, `justify-content-center`, `flex-column`, `flex-md-row`.
  - *Componentes:* `Cards`, `Progress Bars`, `Badges`, `Navbar`, `Buttons`.
- **Bootstrap Icons 1.11:** Iconografía ligera y escalable vía CDN.
- **JavaScript (ES6 Vanilla):** Código conciso para el cierre del menú móvil y copia de correo al portapapeles.
